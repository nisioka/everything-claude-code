# eli5（5歳児にも分かる図解）

そのトピックについて何も知らない人に向けて、**大きな絵と少ない言葉**の HTML アーティファクトで説明する。

トピック: $ARGUMENTS

## 言語（最優先・例外なし）

**成果物の文章はすべて日本語で書く。**

- アーティファクト内のテキスト（`<title>`、見出し、ラベル、キャプション、注釈、図中の文字列すべて）は日本語にする。
- 会話側の説明・要約も日本語で返す。
- ユーザーが英語で質問しても、英語のトピック名（`DNS`、`OAuth` など）を渡してきても、日本語で説明する。トピック名がそのまま英語なのは構わないが、**説明文が英語になってはいけない**。
- ユーザーが「英語で」と明示的に指示した場合のみ、この規則を外す。

### 日本語での書き方

- 専門用語をそのまま置かない。初出の用語には必ず日常語の言い換えを添える（例: 「DNS（インターネットの電話帳）」）。
- カタカナ語の羅列を避ける。「キャッシュ」より「一度調べた答えのメモ」のように、まず日常語で言い、必要なら括弧でカタカナ語を補う。
- 敬体（です・ます）で、一文を短く。1 パネルにつき 1 文が目安。
- ダッシュ（—）や中黒の並列は使わない。
- フォントは日本語が崩れないスタックにする（例: `system-ui, "Hiragino Sans", "Yu Gothic", "Noto Sans JP", sans-serif`）。
- 日本語は改行位置で読みやすさが変わる。折り返してほしい位置は CSS まかせにせず、マークアップで決める。ただし方法は HTML と SVG で異なる。
- **HTML のテキスト**: 意味の切れ目に `<wbr>` を入れ、必ず改行したい箇所は `<br>` にする。CSS は `word-break: keep-all;` と `line-break: strict;` を併用する。`keep-all` は語中で切らせないための指定であって、意味の切れ目を教える指定ではない。`overflow-wrap: anywhere;` は意味を無視して任意の位置で切るため、狭い枠に長い URL や英単語が入ってはみ出すときの最終手段としてのみ使う。
- **SVG のテキスト**: `<text>` の中で `<br>` や `<wbr>` は効かない（SVG の要素ではないため無視される）。また SVG のテキストは自動折り返しをしない。複数行にするときは、行ごとに `<tspan x="...">` を並べて意味の切れ目で改行する。行送りは 2 行目以降の `<tspan>` に `dy="1.2em"` を付けて作る。`dy` は現在位置からの相対移動なので、1 行目に付けるとテキスト全体が 1 行ぶん下へずれる。長い説明をどうしても流し込みたいときだけ `<foreignObject>` に XHTML を入れ、その中では上の HTML のルールに従う。
- そもそも 1 パネルの文は短く保ち、SVG のラベルは折り返しが要らない長さに収めるのが最善。

## 作り方

1. アーティファクトを書く前に `artifact-design` スキルを読み込む。
2. トピックを 3〜6 個の場面に分解する。1 場面 = 1 パネル。
3. 各パネルは「大きな絵（インライン SVG や絵文字）＋ 短い日本語 1 文」で構成する。文字より絵が主役。
4. 身近なたとえを 1 つ決めて、最後まで同じたとえで通す。途中でたとえを乗り換えない。
5. 最後に「つまり何？」を 1 文でまとめる。
6. `Artifact` ツールで公開し、URL をユーザーに渡す。

## やらないこと

- 段落だらけの文章にすること。これは読み物ではなく図解。
- 正確さのために語を増やすこと。細かい例外は切り捨ててよい。ただし嘘は書かない。
- 英語のまま貼り付けた図やラベルを残すこと。
